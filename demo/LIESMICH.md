# Demo mit Beispieldaten

Startet die App aus `../webapp/` mit einer eigenen Demo-Datenbank (`data/demo.sqlite`), z. B. um Designs anzusehen.
Wird nicht hochgeladen.

- Starten: `./starten.sh` → http://127.0.0.1:8090/ (Beenden: Strg+C)
- Anmelden: `demo@example.org` / `demo-56f66ef6`
- Neu befüllen: `data/demo.sqlite` löschen, Server starten, `python3 seed.py` ausführen.
